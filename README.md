\# STM32 环境监测与温控记录仪



基于 STM32F103C8T6 的环境监测与温控记录仪。



\## 功能

\- MPU6050 姿态/温度采集

\- 热敏电阻温度、光敏光照采集

\- OLED 四页显示

\- 超温自动启动风扇（TB6612 + 130 电机）

\- W25Q64 数据记录

\- UART 命令 shell



\## 硬件

STM32F103C8T6、OLED、MPU6050、W25Q64、热敏、光敏、电位器、旋转编码器、TB6612、130 电机、USB 转串口
